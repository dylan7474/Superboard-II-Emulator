1. Booting the Superboard II (`D/C/W/M ?`)

          
On power-up or after pressing BREAK, the SYN600 Monitor displays D/C/W/M ?:

          
    
            
  • C — Cold Start 8K Microsoft BASIC (clears RAM)
    • 
            
  • W — Warm Start BASIC (preserves program in RAM)
    • 
            
  • M — Enter 6502 Machine Language Monitor
    • 
            
  • D — Boot OS-65D Floppy Disk (returns to prompt if no drive)
    • 
          

        


        

          
2. 6502 Machine Language Monitor Commands

          
Inside Monitor mode (M), type uppercase hex commands:

          
    
            
  • .0200 — Set current address pointer to $0200
    • 
            
  • /A9 41 8D 85 D0 60 — Store hex bytes sequentially & advance
    • 
            
  • G — Execute 6502 code at current address (JMP)
    • 
            
  • L — List 64 bytes of hex memory from current address
    • 
            
  • R — Reset back to D/C/W/M ? prompt
    • 
          

        


        

          
3. Superboard II Memory Map

          

            
$0000–$00FF6502 Zero Page

            
$0100–$01FF6502 Hardware Stack

            
$0200–$7FFFUser RAM & BASIC Program

            
$A000–$BFFF8K Microsoft 6502 BASIC ROM

            
$D000–$D3FF1K Video RAM (53248–54271)

            
$DF008×8 Keyboard Matrix (57088)

            
$F800–$FFFF2K SYN600 System Monitor ROM
